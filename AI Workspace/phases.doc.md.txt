## PHASE 5: SPEECH-TO-TEXT

Create a dedicated Speech-to-Text service.

Workflow:

Audio
↓
STT Provider
↓
AI Transcription
↓
Database

Store:

- Audio ID
- Source language
- AI transcription
- Timestamp
- Processing status
- Provider/model metadata where appropriate

Preserve timestamps/segments/confidence information if supported by the provider.

Goal:

Convert real audio into AI-generated transcription.

---

## PHASE 6: AI TRANSCRIPTION DISPLAY

Create the transcription interface.

Show:

- Original audio
- AI-generated transcription
- Source language

- Error state

Goal:

Users/reviewers can clearly inspect the AI output.

---

## PHASE 7: HUMAN REVIEW & CORRECTION

Create Human Review module.

Reviewer should be able to:

- Listen to original audio
- Edit transcription
- Correct spelling
- Correct missing words
- Correct punctuation
- Mark unclear sections
- Add notes
- Submit review

Store separately:

AI Transcription

Human Corrected Transcription

Reviewer

Review Timestamp

Review Status

Goal:

Create a real Human-in-the-Loop AI workflow.

---

## PHASE 8: AI VS HUMAN COMPARISON

Create a comparison interface.

Example:

AI:
"Mujhe kal doctor ke pas jana he."

Human:
"Mujhe kal doctor ke paas jaana hai."

Show:

- Changed words
- Added words
- Removed words
- Number of edits
- Review status

Do not claim that edit statistics are professional linguistic accuracy measurements unless a validated methodology is implemented.

Goal:

Demonstrate how humans improve AI-generated language data.

---
